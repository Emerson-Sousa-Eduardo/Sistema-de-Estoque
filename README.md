#  Sistema de Estoque em Python

##  Sobre o projeto

Este é um sistema simples de gerenciamento de estoque desenvolvido em Python com foco em prática de lógica de programação.

O sistema permite cadastrar, listar, buscar, atualizar e remover produtos utilizando um arquivo de texto como forma de persistência de dados.

O objetivo principal do projeto é consolidar conceitos fundamentais da linguagem Python aplicados em um sistema funcional de terminal.

---

##  Funcionalidades

- Cadastro de produtos
- Listagem de produtos cadastrados
- Busca de produtos por nome
- Atualização de quantidade (em desenvolvimento)
- Remoção de produtos (em desenvolvimento)
- Menu interativo via terminal
- Tratamento básico de erros de entrada

---

##  Conceitos aplicados

- Estruturas de repetição (`while`)
- Condicionais (`if / elif / else`)
- Funções em Python
- Manipulação de arquivos (`open`, `with open`)
- Tratamento de exceções (`try / except`)
- Lógica de CRUD

---

##  Estrutura dos dados

Os produtos são armazenados no arquivo:
estoque.txt


Formato:
nome,quantidade,preco
Exemplo:
Arroz,10,25.90
Feijão,5,8.50
